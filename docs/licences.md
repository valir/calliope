# Dependency licences

Record of every direct dependency and bundled asset of calliope-gui. Licence identifiers
come from the package metadata (`cargo metadata` for crates, `node_modules/<pkg>/package.json`
for npm packages, the font package's `LICENSE`), not from memory. Versions are the ones locked
in `Cargo.lock` / installed from `package-lock.json` when this file was written; the range is
what the manifest asks for.

`tests/frontend.rs` (`licence_record_lists_every_direct_dependency`) fails when a direct
dependency in `Cargo.toml` or `package.json` has no row here. Add the row (with the licence
read from the package metadata) whenever you add a dependency.

**Flagged (not permissive): none.** Every entry is MIT, Apache-2.0, ISC or OFL-1.1; no GPL,
LGPL, MPL or unknown licences. Where a crate is dual-licensed ("MIT OR Apache-2.0") either
may be chosen. Transitive dependencies are not listed here.
